# Project scope

Original work for InterSystems Programming Contest: Build Your Own Management Portal, contest 48. Development started 2026-09-24 after reviewing the official development window beginning September 14. No code from another entry was reused.

The target user is an operator preparing a maintenance handoff. Existing CRUD portals expose present state but make it difficult to explain exactly what changed and what could not be observed. Atlas collects only selected configuration metadata and creates a conservative before/after review. It does not try to replace the full IRIS administration portal or autonomously remediate a database.

Success criteria:

1. Real authenticated API v2 data from a legal free local Community Edition runtime.
2. Exact observed additions/removals/field changes on a controlled local fixture.
3. Missing, failed, partial, or mismatched-source evidence cannot produce false deletion or all-clear results.
4. Usable browser workflow, inspection, filtered ledger, import and exported handoff.
5. Honest original source, clear English documentation, complete public demo, official entry and receipt when account steps permit.

No model API, paid infrastructure, credit card, external dataset, or production access is needed. UI uses original CSS and text, system fonts, and no third-party image assets.

The cash contest awards are competitive, not guaranteed wages. Entry/acceptance, awards, and payment remain distinct states.
